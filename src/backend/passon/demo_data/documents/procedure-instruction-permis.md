# Procédure — instruction d'une demande de permis de construire

Note interne, à conserver pour la reprise du poste.

## Étapes

1. **Enregistrement** (J+0) : dépôt guichet ou en ligne, attribution du numéro
   PC, accusé de réception automatique.
2. **Complétude** (J+0 à J+30) : vérifier les pièces. Toute demande de pièce
   complémentaire doit partir avant J+30, sinon le délai d'instruction est
   figé et le silence vaut acceptation.
3. **Consultations** : ABF systématique dans le périmètre du centre ancien
   (délai 1 mois, souvent 6 semaines en pratique), SDIS pour les ERP.
4. **Décision** : arrêté signé par le maire, notifié en recommandé.

## Pièges à connaître

- L'ABF ne répond presque jamais dans le délai affiché. Relancer à J+20 par
  mail à Mme Delcourt, sinon le dossier dérape.
- Le logiciel ne calcule pas correctement les délais quand une pièce
  complémentaire arrive un vendredi : vérifier à la main.
- Les recours gracieux (actuellement : SCI Vasseur) doivent être traités dans
  les deux mois, faute de quoi le rejet devient implicite et le requérant peut
  saisir le tribunal administratif.
